# TELEGRAM BOT - starter bot
Creator & Builder: Shajeduzzaman Enan

1. Create the bot in @BotFather and copy the token.
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and paste the token.
4. `python bot.py`

Keep this folder inside the resource pack: the bot reads the images from `../13-menu-cards` and the welcome video from `../10-video`.
Commands: /start /menu /help /profile /premium /about
